# Creation option portraits

Optional local art for the guided Create flow, bundled at build time.
Drop files at `{class|species|background}/{slug}.webp`, e.g. `class/wizard.webp`
or `species/half-elf.webp`. The slug is the option name lowercased with
non-alphanumerics replaced by `-`. Options without a file fall back to an
emblem or a monogram. Use a 4:3 image.
